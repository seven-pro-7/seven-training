# GZCLP 训练追踪（SEVEN个人追踪版本）

基于《GZCLP 扩展容量版 8 周追踪表》做的网页版力量训练追踪工具，纯前端、零后端，数据保存在浏览器本地（localStorage）。

**在线地址**：部署到 GitHub Pages 后为 `https://<你的用户名>.github.io/gzclp/`

## 功能
- **训练**：按 A1 → B1 → A2 → B2 推荐当天训练，实时显示判定与下次重量，支持手动调整重量、更换动作、组间休息计时、配重片提示。
- **计划**：8 周 × 4 日矩阵，支持多轮循环（练完一轮自动进入下一轮）。
- **数据**：各动作重量走势、训练容量、e1RM 线性回归、判定分布。
- **回顾**：教练小结、周报、训练日志（可改可删，之后数据自动重算）。
- **设置**：1RM / TM、加重步幅、取整档位、减载、每轮周数、动作库（含自定义动作）。

## 在 iPhone 上当 App 用
用 **Safari** 打开在线地址 → 分享 → **添加到主屏幕**，即可全屏使用、带图标。

> 数据只存在当前浏览器/桌面图标里。建议定期在「设置 → 导出备份文件」导出 JSON 备份。

## 部署（GitHub Pages）
本仓库根目录就是可直接托管的静态站点（`index.html` + 图标 + manifest）。
在仓库 **Settings → Pages** 中把 Source 设为 `main` 分支、`/ (root)` 目录即可。

## 目录
- `index.html` / `icon-*.png` / `manifest.webmanifest`：网页版（单文件自包含）
- `source/`：原生微信小程序工程 + 网页版打包脚本（`source/preview/build.py`）
- 计算规则引擎：`source/utils/engine.js`（小程序与网页版共用）
